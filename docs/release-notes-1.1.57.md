# Release 1.1.57

- Fix Thamon's physical and magical absorption: HP recovery no longer counts as player damage when boss or buff information is missing or stale.
- Reduce automatic merchant overhead and release completed sessions while retaining automatic stock checks.
- Add a button to remove deleted characters from the checklist, with the change saved across restarts.
- Show the mob name beside missing-soul counts on a fully transparent minimap.
- Add estimated per-player stagger to replays using skill-description values during an observed open boss gauge. Unknown data is shown separately; speciality and effect bonuses are not included.
- Fix installer translation selection and show the language selector on interactive installation. Silent updates remain unattended.

Includes the corrected installer language package. Existing saved fight totals are not rewritten.
