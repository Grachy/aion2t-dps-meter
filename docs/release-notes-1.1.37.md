# Release 1.1.37

## New features

- **OBS Browser source:** display your meter in OBS with total damage, DPS/rDPS/HPS, class icons, boss HP and ping.
- **Copy team results as text:** use the copy button or configurable **Ctrl+Z** hotkey. Choose DPS, rDPS, HPS, total damage or DPS plus total damage.
- **Optional CoGM uploads:** enable fight sharing in Advanced settings. Disabled by default; requires manual opt-in.
- **PvP target Gear Score:** added a compact Combat Assist panel for the selected target.
- **Boss timers:** added support for more Global timer packets and server-specific community schedules. Community schedules require the matching server update.

## Bug fixes and improvements

- Fixed final boss damage and fight duration freezing before the last hits were included.
- Fixed Insignia stack counts in Combat Assist.
- Fixed incorrect Global latency readings.
- Fixed stale player identity and damage attribution when switching characters.
- Improved energy tracking so it stays tied to the correct character and server.
- Fixed Combat Assist panels appearing outside the game or while the game was minimized.
- Fixed invisible and duplicate overlay panels blocking game clicks. Normal clicks pass through overlays; hold Alt to edit unlocked panels.
- Fixed unwanted Premium cooldown and buff selections remaining active without Premium access.
- Fixed the missing Invasion resource icon.
