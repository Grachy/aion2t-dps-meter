aion2t.com DPS Meter

Free real-time DPS overlay for Aion 2 — see every party member's damage as it happens.

⬇ Download Latest GitHub aion2t.com

Features

⚡

Real-time DPS

Updates every 500 ms. See all party members' damage output as it happens, live during fights.

📊

Skill Breakdown

Click any player to see a detailed breakdown by skill — icons, hit counts, and a damage timeline chart.

🎯

Boss Tracking

Automatically detects the current boss and shows the total damage dealt to it by each player.

👥

Party Selector

Running multiple instances or parties? Switch between them on the fly without restarting the app.

🪟

Transparent Overlay

Always-on-top transparent window. Resize it by dragging any edge. Stays out of the way while you play.

🌐

10 Languages

EN · RU · DE · FR · ES · PT · 日本語 · 한국어 · 简中 · 繁中 — switch in the settings panel.

🔍

Auto-detect Local Player

Your own character is highlighted automatically. No manual setup required.

🔄

Auto-updates

The app checks for new versions and notifies you when one is available.

Installation

1

Download the installer from the Releases page.
File: aion2t.com DPS_x.x.x_x64-setup.exe

2

Run the installer. If Windows SmartScreen appears, click More info → Run anyway.

3

Launch aion2t.com DPS from the Start menu or desktop shortcut.

4

Start Aion 2 and enter a dungeon — the overlay populates automatically as combat begins.

Hotkeys

Ctrl+R Reset all DPS data
Drag edge Resize overlay window
