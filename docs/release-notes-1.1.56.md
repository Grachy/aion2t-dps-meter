# Release 1.1.56

- Improve capture recovery across game connection changes and temporary ownership gaps.
- Follow the actual game process for background merchant checks, including when the launcher starts first.
- Close the merchant helper and release its driver on full meter exit; clean up leftover helper processes and driver locks during installation and removal.
- Update minimap collection progress and hidden-cube display.
- Expand the merchant Rare category to 49 pets, including Flame Stone Guardian Statue, Pino Worker and Tog.

Closing the meter while a merchant relay session is active can cause the game to reconnect.
